# Insructions
Click "Folder" -> "Open..." to open directory with music files.

Click music file name to load it.

Click "Audio clip" to choose any clip manually.

Click "Play", "Stop" to control music playing, click loop to loop while playing.

Click & Hold LMB to choose sector, press CTRL+A to select all.

Click & Hold RMB to add/drag keys, press square to remove key. Press Delete to remove keys in selected sector.

Click "Database" -> "Open" & "Save" to manage keys database. Make sure to load database if it exists before performing any work.

Under "Database" shown list of stored keys for each song. Click "Import" to import stored keys into current clip, click "X" to delete recorded data.

Scroll MMB to zoom. Press CTRL+Z to zoom into selected sector.

Click "Analyze music" to determine & display music beats.

Click "Place beats" | Click "B" to transfrom beats into keys. "Period" is used to control how keys distributed. E.g. 0 - means 1 beat = 1 key; 0.5 means than 1 beat = 1 key, but keys will be placed between beats. 2 means each one beat will be skipped and key will be placed; etc.

Click "Get BPM" to compute beats per minute on selected sector, music must be analyzed first.
